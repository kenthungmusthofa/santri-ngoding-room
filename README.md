# santri-ngoding-room
Ruang eksperimen digital tempat seorang santri mencoba berdamai dengan bug, sintaks error, dan takdir. Repository ini berisi catatan belajar, proyek kecil, serta eksplorasi teknologi yang dikerjain sambil tetap menjaga adab. Tempat ngoding sambil ngaji, atau ngaji sambil ngoding, terserah mana yang duluan.
